## 📦 Installation

### Prerequisites
- Python 3.9 or higher
- Node.js 16+ (optional, for development tools)
- Modern web browser

### Clone Repository

```bash
git clone https://github.com/UmasankarE/AI-Design-Your--Dream-Interior.git
cd AI-Design-Your--Dream-Interior
```

### Run Locally (Frontend Only - Module 1)

#### Option 1: Using Python
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

#### Option 2: Using Live Server (Node.js)
```bash
npm install -g live-server
live-server
```

#### Option 3: Direct Browser
Just open `index.html` directly in your web browser.
